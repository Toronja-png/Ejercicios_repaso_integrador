# Ejercicio 14: Funciones — parámetros y retorno

### Consigna

Crear un archivo `ej14.py` que contenga las siguientes **funciones**. Cada función debe **devolver** el
resultado (con `return`), **nunca imprimir**. La impresión es responsabilidad de quien la llama.

| Función | Qué hace | Qué recibe | Qué devuelve |
| --- | --- | --- | --- |
| `es_par(numero)` | Indica si un número es par | un `int` | `True` o `False` |
| `es_primo(numero)` | Indica si un número es primo | un `int` | `True` o `False` |
| `mayor_de_tres(a, b, c)` | Devuelve el mayor de tres números | tres números | el mayor |
| `promedio(lista)` | Devuelve el promedio de una lista | una lista de números | el promedio |
| `contar_vocales(texto)` | Cuenta las vocales de un texto | un `str` | la cantidad de vocales |

Además:

1. Escribir una función `main()` que pida los datos al usuario, llame a las funciones anteriores y muestre
   los resultados.
2. Escribir una función `es_bisiesto(anio)` que devuelva `True` si el año es bisiesto y `False` si no lo es.
   (Un año es bisiesto si es divisible por 4, **excepto** si es divisible por 100 y **no** por 400.)
3. Escribir una función `mayor_de_lista(lista)` que devuelva el número más grande de una lista. **No** usar
   `max()`: hay que recorrerla.

### Ejemplo de ejecución

```
Ingrese un número entero: 17
El número 17 es primo.
Ingrese un año: 1900
El año 1900 no es bisiesto.
```

### Pistas

- La estructura de una función es:
  ```
  def nombre(parametro):
      # lo que hace
      return resultado
  ```
- Los parámetros pueden tener un valor por defecto: `def saludar(nombre, saludo="Hola"):`.
- Una función que devuelve varios valores en realidad devuelve una **tupla**, que se puede desempacar:
  `minimo, maximo = obtener_extremos(lista)`.

### Para pensar

¿Qué pasaría si una función no tiene `return`? ¿Qué devuelve? ¿Por conviene que las funciones devuelvan
el resultado en lugar de imprimirlo? Escribí una función que devuelva **dos** valores a la vez (por ejemplo, el
mayor y el menor de una lista) y desempácala en dos variables.
