# Ejercicio 10: Matrices — creación y recorrido

### Consigna

Crear un archivo `ej10.py` que trabaje con **matrices** (listas de listas).

1. Construir una matriz de **3 filas y 3 columnas** pidiéndole los 9 valores al usuario. Al final, mostrar
   la matriz completa.
2. Recorrer la matriz con un `for` anidado e imprimir cada elemento en formato `matriz[fila][columna] = valor`.
3. **Sumar todos los elementos** de la matriz y mostrar el total.
4. **Sumar cada fila** y mostrar el resultado de cada una (el vector de sumas por fila).
5. **Sumar cada columna** y mostrar el resultado de cada una (el vector de sumas por columna).
6. **Sumar la diagonal principal** y la **diagonal secundaria** de la matriz.

### Ejemplo de ejecución (fragmento)

```
La matriz es:
[[1, 2, 3], [4, 5, 6], [7, 8, 9]]

matriz[0][0] = 1
matriz[0][1] = 2
...

Suma de todos los elementos: 45
Suma de cada fila: [6, 15, 24]
Suma de cada columna: [12, 15, 18]
Suma de la diagonal principal: 15
Suma de la diagonal secundaria: 15
```

### Pistas

- Para crear la matriz vacía con sus filas: 
  ```
  matriz = []
  for i in range(3):
      matriz.append([])
  ```
  y después se le piden los valores con un `for` anidado.
- La diagonal principal son los elementos donde **fila == columna**. La diagonal secundaria son los elementos
  donde **fila + columna == (cantidad de filas - 1)**.
- Para mostrar la matriz en filas (y no en una sola línea) se puede recorrer con `for fila in matriz:` y
  `print(fila)`.
