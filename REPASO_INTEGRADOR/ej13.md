# Ejercicio 13: Diccionarios con listas y diccionarios anidados

### Consigna

Crear un archivo `ej13.py` que combine diccionarios con otras estructuras de datos.

### Parte 1: Diccionario con listas de notas

1. Cargar un diccionario `notas` donde la **clave** es el nombre del alumno y el **valor** es una **lista** con
   sus notas. Por ejemplo:
   ```
   notas = {
       "Juan": [8, 9, 7],
       "Ana": [5, 6, 4]
   }
   ```
2. Mostrar el **promedio de cada alumno** (con dos decimales).
3. Mostrar el **promedio general** de todos los alumnos.
4. Mostrar el alumno con **mayor promedio** y el de **menor promedio**.

### Parte 2: Diccionario anidado (inventario)

5. Cargar un diccionario `inventario` donde cada **clave** es el nombre del producto y el **valor** es **otro
   diccionario** con su precio y su stock:
   ```
   inventario = {
       "teclado": {"precio": 25000, "stock": 15},
       "mouse": {"precio": 15000, "stock": 30}
   }
   ```
6. Mostrar cada producto con su precio y su stock.
7. Mostrar el **valor total del inventario** (precio × stock de cada producto, sumado).
8. Mostrar el **producto con mayor stock** y el **precio promedio** de todos los productos.

### Ejemplo de ejecución (fragmento)

```
Juan: 8.00
Ana: 5.00
Promedio general: 6.50
Alumno con mejor promedio: Juan (8.00)

teclado -> precio: $25000, stock: 15
mouse -> precio: $15000, stock: 30

Valor total del inventario: $825000
```

### Pistas

- Para acceder a un valor anidado: `inventario["teclado"]["precio"]`.
- Para recorrer el diccionario externo y tener clave y valor: `for nombre, datos in inventario.items():`.
- Un diccionario puede ser recorrido con `for` igual que una lista, y también se le puede pedir su largo
  con `len()`.

### Desafío extra

Contar cuántas palabras aparecen en una frase y cuántas veces aparece cada una, usando un diccionario
(cada palabra es una clave y la cantidad de apariciones es el valor). Mostrar el resultado ordenado de la
palabra más repetida a la menos repetida.
