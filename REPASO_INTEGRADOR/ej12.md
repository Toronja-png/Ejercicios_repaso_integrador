# Ejercicio 12: Diccionarios — carga, acceso y recorrido

### Consigna

Crear un archivo `ej12.py` que trabaje con un diccionario de productos.

1. Cargar un diccionario `productos` con **5 productos**: la **clave** es el nombre del producto y el
   **valor** es su precio.
2. Mostrar el diccionario completo.
3. Mostrar **todas las claves** por un lado y **todos los valores** por otro.
4. Mostrar cada producto con su precio usando `items()`, con el formato:
   ```
   Teclado: $25000
   Mouse: $15000
   ```
5. **Consultar** el precio de un producto pedido por el usuario. Si el producto **no existe**, avisar
   que no se encontró (sin que el programa se rompa).
6. **Actualizar** el precio de un producto, sumándole un 10 %.
7. **Agregar** un producto nuevo y **eliminar** un producto existente.
8. Mostrar cuántos productos hay en el diccionario (`len`).

### Ejemplo de ejecución (fragmento)

```
--- Diccionario completo ---
{'teclado': 25000, 'mouse': 15000, 'monitor': 120000, 'auriculares': 30000, 'parlantes': 45000}

Claves: ['teclado', 'mouse', 'monitor', 'auriculares', 'parlantes']
Valores: [25000, 15000, 120000, 30000, 45000]

Teclado: $25000
Mouse: $15000
...

Ingrese el producto a consultar: webcam
El producto "webcam" no se encuentra en el diccionario.
```

### Pistas

- Se agrega un elemento con `diccionario[clave] = valor`.
- Para saber si una clave existe: `if clave in diccionario:`. Para obtener un valor sin romperse:
  `diccionario.get(clave, "no encontrado")`.
- Para eliminar: `del diccionario[clave]`.
- `diccionario.keys()`, `diccionario.values()` y `diccionario.items()` devuelven objetos iterables.
