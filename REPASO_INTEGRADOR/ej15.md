# Ejercicio 15: Integrador — Sistema de gestión de alumnos de la ETec

### Consigna

Este ejercicio **reúne todo lo visto**. Hay que escribir un programa completo que use **condicionales**,
**bucles**, **listas**, **matrices**, **diccionarios** y **funciones**, con un menú interactivo.

El sistema administra los alumnos de la Escuela Técnica. Los datos se guardan en un diccionario `alumnos`,
donde la **clave** es el DNI y el **valor** es **otro diccionario** con los datos del alumno:

```
alumnos = {
    # Vacío al principio
}

# Ejemplo de cómo queda un alumno cargado:
# 30000000: {"nombre": "Juan Perez", "notas": [8, 9, 7]}
```

### Menú

El programa debe mostrar, indefinidadamente, el siguiente menú:

```
1. Cargar alumno
2. Mostrar todos los alumnos (con su promedio)
3. Buscar alumno por DNI
4. Mostrar el alumno con mejor promedio
5. Mostrar grilla de alumnos
6. Salir
```

### Comportamiento de cada opción

1. **Cargar alumno:** pedir DNI, nombre y las notas del alumno (por ejemplo, 3 notas). Si el DNI ya está
   cargado, avisar que el alumno ya existe. Guardar el alumno en el diccionario.
2. **Mostrar todos los alumnos:** recorrer el diccionario y mostrar cada alumno con su promedio. Si no hay
   alumnos cargados, avisar.
3. **Buscar alumno por DNI:** pedir el DNI y mostrar los datos del alumno. Si no existe, avisar.
4. **Mejor promedio:** mostrar el alumno con el mayor promedio. Si no hay alumnos, avisar.
5. **Grilla de alumnos:** mostrar los **nombres de los primeros 9 alumnos** en una **matriz de 3 x 3**, con el
   formato de la parte 5 del eje de matrices. Si hay menos de 9 alumnos, las posiciones vacías se muestran
   con un guion (`-`).
6. **Salir:** el programa termina.

### Requisitos de implementación

- Cada opción del menú debe estar implementada en una **función** propia (por ejemplo, `cargar_alumno()`,
  `mostrar_alumnos()`, `buscar_alumno()`, `mejor_alumno()`, `mostrar_grilla()`), y una función `main()` que
  se encargue del menú y del `while`.
- El **promedio** de un alumno se debe calcular en una función aparte, que reciba su lista de notas y
  devuelva el promedio.
- El programa debe **validar** la opción del menú: si el usuario escribe algo que no sea un número entre 1 y 6,
  debe avisar y volver a mostrar el menú.

### Ejemplo de ejecución (fragmento)

```
1. Cargar alumno
2. Mostrar todos los alumnos (con su promedio)
3. Buscar alumno por DNI
4. Mostrar el alumno con mejor promedio
5. Mostrar grilla de alumnos
6. Salir

Ingrese una opción: 1
Ingrese el DNI: 30000000
Ingrese el nombre: Juan Perez
Ingrese la nota 1: 8
Ingrese la nota 2: 9
Ingrese la nota 3: 7
Alumno cargado correctamente.

Ingrese una opción: 2
DNI 30000000 - Juan Perez - Promedio: 8.00
```

### Pistas

- Para mostrar los promedios usá f-strings: `f"DNI {dni} - {nombre} - Promedio: {promedio:.2f}"`.
- La grilla se puede armar con una matriz de 3 filas y 3 columnas, rellenando con `append`.
- Para recorrer el diccionario de alumnos: `for dni, datos in alumnos.items():`.

### Desafío final

Agregá la opción **7. Mostrar alumnos aprobados**: debe mostrar los alumnos cuyo promedio sea mayor o igual a 6,
usando una lista para guardar a los aprobados y un `for` para recorrerla.
